# tools4devs selected identity

Selected direction: straight T, longer four crossbar, heavier strokes, clear knockout. Flat colors only.

## Assets

- app-icon.svg: T4D squircle for large sizes.
- app-icon-inverted.svg: off-white monogram on blue.
- small-icon.svg and favicon.svg: simplified blue four.
- wordmark-dark.svg and wordmark-light.svg: outlined Inter Tight Semibold; only the four is blue.
- icon-16.png through icon-1024.png: transparency retained outside the squircle. Sizes through 40 px use the four; sizes from 48 px use T4D.
- app-icon.ico: Windows multi-size icon with the corresponding small/large variants.
- favicon.ico: four-only browser icon.
- tools4devs-final-mockup.png: presentation with illustrative placement studies, not screenshots of the installed app or live site.

The SVGs contain outlined geometry and have no font dependency. Inter Tight is licensed under SIL OFL; see OFL.txt.

Palette: navy #151C2A, off-white #F2F4F7, blue #3E83D5. Solid color contrast: off-white/navy 15.48:1, blue/navy 4.40:1, off-white/blue 3.52:1. Recognition at small sizes is handled by the four-only variant, not by those color ratios.

These assets have not yet been applied to the desktop app or landing page.
